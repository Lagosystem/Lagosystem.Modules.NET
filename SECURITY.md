# Security policy / Política de segurança

## English

Security reports are welcome. Do **not** open a public Issue for a suspected vulnerability, or include exploit steps, secrets, personal information or production data in public code.

Where enabled, use the repository's [private vulnerability reporting](https://github.com/Lagosystem/Lagosystem.Modules.NET/security/advisories/new). If the GitHub private-reporting form is unavailable, request a private contact channel from the organization maintainers without posting technical exploit details.

Provide affected library version/commit, impact, reproduction outline and mitigation ideas via the **private** channel. The maintainers will triage reports and coordinate disclosure; no fixed response-time or bounty program is promised.

No stable NuGet release has been confirmed. Report potential supply-chain, dependency, XML/JSON, path traversal, validation, unsafe-memory and denial-of-service vulnerabilities.

## Português brasileiro

Não utilize Issues públicas para reportar vulnerabilidades e não divulgue passos de exploração, segredos ou dados de produção.

Se habilitado, utilize [relato privado de vulnerabilidades](https://github.com/Lagosystem/Lagosystem.Modules.NET/security/advisories/new). Se a opção não estiver disponível, solicite aos mantenedores um canal privado, sem publicar detalhes técnicos sensíveis.

Informe commit/versão afetada, impacto, reprodução resumida e possíveis mitigações em canal privado. Os mantenedores avaliarão e coordenarão a divulgação, sem compromisso de SLA ou recompensa.

Ainda não foi confirmada publicação estável no NuGet.
