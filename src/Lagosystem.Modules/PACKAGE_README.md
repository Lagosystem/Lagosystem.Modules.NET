# Lagosystem.Modules.NET

Reusable, open-source utilities and extensions for .NET, developed by **Lagosystem**.

**Target framework:** .NET Standard 2.1  
**License:** Apache-2.0

## Install

```bash
dotnet add package Lagosystem.Modules.NET
```

## Features

- String, enumeration, numerical, and collection extensions
- Data validation and formatting utilities, including Brazilian identifiers
- Financial calculations and conversions
- Diagnostics, memory helpers, and localized error messages

The NuGet package ID is **Lagosystem.Modules.NET**. The compiled assembly and namespaces remain **Lagosystem.Modules**.
